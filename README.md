# Políticas de Asistente YaYa

Landing estática con la **Política de Privacidad** de **Asistente YaYa**, desarrollada por **Sicilia Labs**.

## Contenido del repositorio

- `index.html`: página principal con la política de privacidad.
- `styles.css`: estilos base de la landing de Sicilia Labs y ajustes específicos para la página de política.

## Vista local

Para previsualizar el sitio localmente:

```powershell
Start-Process .\index.html
```

O con un servidor local:

```powershell
python -m http.server 8000
```

Luego abrí `http://localhost:8000`.

## Despliegue

El sitio está publicado con **GitHub Pages** desde la rama `main`, carpeta raíz (`/`).
