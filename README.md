# Landing de Políticas - Asistente YaYa

Landing estática con la Política de Privacidad de **Asistente YaYa**, desarrollada por **Sicilia Labs**.

## Contenido

- `index.html`: página principal con la política de privacidad.
- `styles.css`: estilos de la landing.

## Publicar en GitHub Pages

1. Creá un repositorio en GitHub (por ejemplo, `politicas-yaya`).
2. En esta carpeta, inicializá git y subí los archivos:

```bash
git init
git add .
git commit -m "Add privacy policy landing page"
git branch -M main
git remote add origin https://github.com/<TU_USUARIO>/<TU_REPO>.git
git push -u origin main
```

3. En GitHub, abrí **Settings > Pages**.
4. En **Build and deployment**, elegí:
   - **Source**: Deploy from a branch
   - **Branch**: `main`
   - **Folder**: `/ (root)`
5. Guardá la configuración. GitHub Pages publicará el sitio en unos minutos.
